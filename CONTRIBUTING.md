# Contributing to abdiel-think-in-japanese

Maintained by ProgreTech LLC and Ed Rodriguez. Help is welcome with Japanese-language accuracy, Spanish localization, keyboard accessibility, and offline study workflows.

## Start with an issue

Use [the issue tracker](https://github.com/eabdiel/abdiel-think-in-japanese/issues) to describe a bug or propose an improvement. Include your operating system, application version or commit, reproduction steps, expected behavior, and actual result. Use small synthetic examples and sanitized logs; omit credentials, private records, and customer data.

For larger changes, describe the intended behavior and discuss scope before implementation. Do not assume that an idea in the roadmap is already implemented.

## Submit a focused pull request

1. Fork the repository and create a branch for one change.
2. Follow the setup and limitations in the README and relevant project documentation.
3. Update documentation alongside changed behavior.
4. Run the relevant checks and state exactly what you verified, including platform or hardware limitations. A documentation-only change can be checked by previewing Markdown and verifying links.
5. Explain the problem, resulting behavior, validation, and any remaining limitations in the pull request.

## Working together

Keep discussion respectful, concrete, and focused on the project. Useful reports and documentation contributions matter as much as code. Do not post security-sensitive details in a public issue; use GitHub private vulnerability reporting if the repository offers it.
